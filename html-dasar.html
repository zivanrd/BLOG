🌐 Belajar HTML Dasar

Mengenal dasar-dasar HTML sebagai fondasi dalam membuat website.

Apa Itu HTML?

HTML merupakan singkatan dari HyperText Markup Language. HTML adalah bahasa markup yang digunakan untuk membuat struktur sebuah halaman website. Dengan HTML, kita dapat membuat judul, paragraf, gambar, tabel, tombol, formulir, hingga berbagai elemen lain yang ditampilkan oleh browser.

HTML bukan bahasa pemrograman karena tidak digunakan untuk membuat logika seperti perulangan atau perhitungan. HTML hanya mengatur susunan isi halaman agar dapat dibaca dan ditampilkan dengan baik oleh browser.

Sejarah HTML

HTML pertama kali diperkenalkan oleh Tim Berners-Lee pada tahun 1991. Tujuan awalnya adalah memudahkan pertukaran dokumen melalui internet. Seiring berkembangnya teknologi, HTML mengalami banyak pembaruan hingga kini menggunakan HTML5 yang memiliki fitur lebih lengkap.

Mengapa Harus Belajar HTML?

HTML merupakan dasar dari semua website yang ada di internet. Sebelum mempelajari CSS atau JavaScript, seseorang harus memahami HTML terlebih dahulu.

  • Mudah dipelajari oleh pemula.
  • Menjadi dasar pembuatan website.
  • Dapat dipadukan dengan CSS dan JavaScript.
  • Digunakan oleh hampir semua website.
  • Mudah dikembangkan menjadi website profesional.

Struktur Dasar HTML

<!DOCTYPE html>
<html>

<head>
    <title>Website Pertama</title>
</head>

<body>

    <h1>Halo Dunia</h1>
    <p>Selamat datang di website saya.</p>

</body>

</html>

Semua halaman HTML memiliki struktur dasar seperti di atas agar browser dapat memahami isi dokumen dengan benar.

Tag HTML yang Sering Digunakan

  • <html> : Tag utama HTML.
  • <head> : Informasi halaman.
  • <body> : Isi website.
  • <h1> sampai <h6> : Judul.
  • <p> : Paragraf.
  • <a> : Link.
  • <img> : Menampilkan gambar.
  • <table> : Membuat tabel.
  • <form> : Membuat formulir.

Contoh Membuat Judul dan Paragraf

<h1>Belajar HTML</h1>

<p>
HTML adalah bahasa markup.
</p>

Contoh Membuat Link

<a href="index.html">
Kembali ke Beranda
</a>

Contoh Menampilkan Gambar

<img src="gambar/html.jpg"
alt="HTML">

Contoh Membuat List

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

HTML, CSS, dan JavaScript

Dalam pengembangan website, HTML, CSS, dan JavaScript saling melengkapi.

  • HTML mengatur struktur halaman.
  • CSS mengatur tampilan.
  • JavaScript membuat website menjadi interaktif.

Tips Belajar HTML

  • Pelajari tag dasar terlebih dahulu.
  • Sering latihan membuat halaman web.
  • Gunakan VS Code.
  • Gunakan Live Server.
  • Jangan takut mencoba.
  • Pelajari CSS setelah memahami HTML.

Kesalahan yang Sering Dilakukan Pemula

  • Lupa menutup tag HTML.
  • Salah menulis nama file.
  • Penempatan gambar tidak sesuai folder.
  • Salah menulis atribut.
  • Tidak menggunakan struktur HTML lengkap.

Kesimpulan

HTML adalah fondasi utama dalam pembuatan website. Dengan memahami HTML, seseorang dapat membuat struktur halaman web yang rapi dan mudah dikembangkan menggunakan CSS serta JavaScript. Menguasai HTML merupakan langkah awal yang sangat penting bagi siapa pun yang ingin menjadi seorang web developer.
